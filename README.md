> 面向 A 股投资者的 **AI 辅助盯盘与决策支持系统**。

## 为什么做这个

散户盯盘的痛点很具体：行情软件信息过载、决策全靠感觉、复盘三天就忘；而市面上的"AI 荐股"要么黑箱、要么让模型直接编价格——**在金融场景里不可信，也不敢用**。

TickerView 的做法是给 AI **划清边界**：所有数字和信号由可复现的规则算出来，大模型只把结果翻译成人话。工具不承诺超额收益，它提供的是**信息聚合、纪律执行与可验证性**。

## 核心功能

**实时盯盘**
- 上证 / 深成 / 创业板指数快照 + 自选股池实时行情（价 / 涨跌 / 换手 / 量比）
- 日 K / 30 分 K 蜡烛图，叠加均线与**关键位叠线**；分时图（含均价线）、成交量副图
- 持仓高亮、A 股习惯的**红涨绿跌**（语义色固定）
- 托盘常驻悬浮面板，数据与网页端同源

**盘前 · 市场状态灯**
- 只回答一件事：**今天有没有事件让策略别乱动**。不替你做决策、不做技术判断
- 全确定性定级：来源分级 → 关键词命中（极性 × 严重级 + 否定排除）→ 🟢正常 / 🟡谨慎 / 🔴警惕
- 利好不抵消利空、当日只升不降；红/黄**只提示"少动、别新开仓"，绝不碰你的止损、不自动改参数**

**盘中 · 快照与信号（ETF / 个股双模式）**
- **ETF 模式**：确定性快照 + 一句话信号 + LLM 深入分析 + 收盘反事实推演
- **个股模式**：风险监控快照 + 状态机（破位 / 成本 / 深回撤 / 涨跌停停牌…），**只提示风险，不给买卖建议**

**盘后 · 建议验证日历**
- 盘中每次快照自动归档当日建议；每条有方向的建议在 **3 / 5 个交易日后自动判定"应验 / 未应验"**，形成客观的效果台账（纯本地、零推送）

**设置**
- 模型（多 LLM 配置 + 连通测试）· 持仓（持仓卡 + 账户现金底线）· 通用（刷新间隔 / 托盘偏好）

## 🧠 AI 在这里到底做了什么

**AI 只做一件事：把引擎算好的事实，翻译成人话。它不负责算，也不负责决策。**

举个真实的盘中流程，你一看就懂：

1. 你点「**刷新快照**」→ 引擎读实时价 + 日线，算出均线、量比、关键位关系，产出一条**确定性信号**，例如"收盘跌破 M20、量比 1.8 → 破位·减仓档"。**这一步没有 AI，全是规则。**
2. 你点「**深入分析**」→ 把上面这些**已经算好的数字**交给大模型，让它写成一段人话："今天该标的跌破 20 日均线且成交放大，按你设定的规则进入减仓档；250 日线仍在下方提供支撑……"
3. 模型**只能引用引擎给过的数字**。如果它凭空写了个引擎没给的价格、或方向自相矛盾，**校验链会打回**；再失败就退回只显示确定性卡片——**宁可少说，不可说错**。

盘前也一样：今早抓到一条 S 级利空（如"证监会立案"），**规则**直接把状态灯定为 🔴；AI 只在下面的证据列表里给每条消息标个利好/利空旁注，**不参与定级**。

所以在这套系统里，分工非常清楚：

| 谁 | 干什么 | 特点 |
|---|---|---|
| **规则引擎** | 算价格关系、信号、盘前定级、盘后验证 | 可复现、可审计，不碰大模型 |
| **大模型** | 把事实写成通顺解读、给消息打标签 | 不产数字、不做判断，出错就降级 |
| **你** | 看提示、做决策、下单 | 工具永远不替你交易 |

## 数据源

全部来自公开数据源，工具**不接入任何交易账户、不下单**：

- **实时行情 / 指数 / 分时**：腾讯行情、同花顺场内快照
- **日 K / 30 分 K**：腾讯行情接口（akshare 补充）
- **隔夜新闻**：新浪财经 7×24 快讯
- **板块异动 / 热榜**：同花顺
- **回测指标计算**：TA-Lib

## 技术栈

- **后端**：Python · Flask · SQLite · akshare · 多数据源直连与降级 · TA-Lib
- **前端**：Vue 3 · ECharts（本地 vendor，无 CDN 依赖）
- **桌面**：pywebview（Edge WebView2）· pystray（系统托盘）· Pillow（图标）
- **打包**：PyInstaller（onedir）· Inno Setup（当前用户免管理员安装）
- **AI**：多免费大模型自动故障切换（密钥仅存本地，绝不入库 / 上传）

## 📦 安装（普通用户）

1. 到 **[Releases](../../releases)** 下载 `TickerView-Setup-0.2.0.exe`
2. 双击安装 —— **当前用户、无需管理员权限**，默认装到 `%LOCALAPPDATA%\Programs\TickerView`（可改到 D 盘等）
3. 开始菜单 / 桌面出现「TickerView」，点开即用；程序常驻**系统托盘**

**系统要求**：Windows 10 / 11（64 位）。Win11 自带 WebView2；Win10 多数随 Edge 更新已具备，安装器也会兜底。

<summary>首次运行的 SmartScreen 提示？</summary>

本项目未做付费代码签名，首次运行可能弹「Windows 已保护你的电脑 / 未知发布者」，点 **更多信息 → 仍要运行** 即可。
</details>

**免安装便携版**：下载 `TickerView-portable.zip`，解压后双击 `TickerView.exe`（不写注册表、不留卸载项）。

**数据在哪**：配置与数据库落在 `%APPDATA%\TickerView\`（`config\` + `data\alphaprism.db`）。**卸载保留数据**，重装即用。全新安装为空白自选，自行添加即可。

> 桌面版开箱即用地提供**实时盯盘与确定性信号**；盘前消息定级、盘中 LLM 深入分析等能力需联网取数、并在设置里配置大模型密钥后启用。

## 🔨 从源码运行（开发者 / 完整引擎）

```bash
# 1) 安装依赖（建议 Python 3.11+）
pip install -r requirements.txt

# 2) 桌面悬浮面板（自动拉起本地服务 + 托盘常驻）
python scripts/cli.py panel

# 或纯 Web 看板（浏览器打开 http://127.0.0.1:8765）
python scripts/cli.py web
```

数据抓取、信号、回测引擎等研究层能力见 `scripts/cli.py` 子命令（如 `daily` / `signal`）。LLM 相关需在 `config/settings.local.yaml`（已 gitignore）配置密钥。
