## 为什么做这个

盯盘这件事，散户的痛点很具体：

- **信息过载**：自选十几只标的，快讯满天飞，重要消息淹没在噪音里；
- **复盘没人对账**：各种"AI 荐股"每天产出大量观点，却从不回头看"上次说对了没有"——你无法分辨它是真有水平还是碰运气；
- **AI 工具不敢信**：黑箱的判断没法验证，模型还会一本正经地编造价格。

TickerView 的答案是把账算清楚给你看：**信息帮你聚合、纪律帮你提醒，而且每一条带方向的判断，都会在几天后自动对账，成绩单直接摆在日历上**。你不用信我，你看账。

## 它每天怎么帮你

### 盘前 · 一分钟知道"今天有没有事"

早上打开，全市场百条级快讯已经由 AI 筛成 **5–8 条真正重要的消息**，每条标好利好/利空、关联板块、置信度；顶部状态灯 🟢🟡🔴 直接告诉你今天适不适合动——红灯只提醒"少动、别新开仓"，**不会碰你的止损、不会替你做任何决定**。

### 盘中 · 一眼看懂一只标的

对着自选里的 ETF 或个股点「刷新快照」，引擎把均线关系、量比、关键位全部算好，一条**一句话信号**告诉你它处于什么状态、对应哪个操作档位。

想听展开讲解？「深入分析」由 AI 接手——但它是**拿着引擎刚算好的数字写解读**：每个价格都有出处，编不出来的；万一模型抽风，多道校验直接打回，**你看到的分析要么准确、要么干脆不出现，不存在"看起来很有道理的胡说八道"**。ETF 还支持**反事实推演**："如果跌破 X 会怎样"这类问题，答案基于规则推演，不是模型想象。

个股走的是另一条刻意不同的路线：**只盯风险，不给买卖建议**——档位升到风险级会提醒你减仓警惕，但永远不会告诉你"买点到了"。买点决策留给你自己。

### 盘后 · 每条建议都有成绩单

这是 TickerView 和所有"AI 荐股"最不一样的地方：**盘中给出的每条有方向的建议，都会在 3 / 5 个交易日后自动判定"应验 / 部分应验 / 未应验"**。

打开验证日历，过去 90 天每条建议的成色一目了然——这个工具最近到底靠不靠谱，不用听我解释，账就摆在那里。纯本地运行，零推送打扰。

## 🧠 为什么这里的 AI 内容可以信

三个设计，保证你看到的每一句 AI 产出都立得住：

1. **AI 只翻译、不计算**——所有数字由可复现的引擎算出来，AI 的工作是把事实讲成人话。它不产价格、不判级、不决策。
2. **每个数字有出处**——AI 输出的价格必须能在引擎快照里找到出处，找不到就视为编造、直接打回；方向词、状态词全部锁定白名单。**宁可少说，不可说错**。
3. **模型挂了照样用**——多模型自动切换，全挂了就降级到关键词筛选、再降级到原始快讯（明确标注"未经 AI 筛选"），**任何单点故障都不中断产品、更不会编造内容**。

一句话：**AI 的边界划得很清楚——它帮你省时间，你保留全部判断权**。

## 实时盯盘（基础能力）

- 上证 / 深成 / 创业板指数快照 + 自选池实时行情（价 / 涨跌 / 换手 / 量比）
- 日 K / 30 分 K 蜡烛图 + 均线系统；分时图（含均价线）、成交量副图
- 持仓高亮、A 股习惯的**红涨绿跌**
- 悬浮面板 / Web 看板 / 托盘常驻，数据同源

## 数据源

全部来自公开数据源，**不接入任何交易账户、不下单**：

- 实时行情 / 指数 / 分时：腾讯行情、同花顺场内快照
- 日 K / 30 分 K：腾讯行情接口（akshare 补充）
- 快讯：新浪财经 7×24、东方财富
- 板块异动 / 热榜：同花顺

## 📦 安装（普通用户）

1. 到 **[Releases](../../releases)** 下载 `TickerView-Setup-0.1.0.exe`
2. 双击安装 —— **当前用户、无需管理员权限**，默认装到 `%LOCALAPPDATA%\Programs\TickerView`（可改到 D 盘等）
3. 开始菜单 / 桌面出现「TickerView」，点开即用；程序常驻**系统托盘**

**系统要求**：Windows 10 / 11（64 位）。Win11 自带 WebView2；Win10 多数随 Edge 更新已具备，安装器也会兜底。

<details>
<summary>首次运行的 SmartScreen 提示？</summary>

本项目未做付费代码签名，首次运行可能弹「Windows 已保护你的电脑 / 未知发布者」，点 **更多信息 → 仍要运行** 即可。

</details>

**数据在哪**：配置与数据库落在 `%APPDATA%\TickerView\`。**卸载保留数据**，重装即用；全新安装为空白自选，自行添加即可。

> 桌面版开箱即用提供实时盯盘与信号；盘前消息筛选、盘中 AI 深入分析需在设置里配置大模型密钥后启用（支持免费模型，多供应商自动切换）。

## 🔨 从源码运行（开发者）

```bash
pip install -r requirements.txt        # Python 3.11+

python scripts/cli.py panel            # 桌面悬浮面板（自动拉起本地服务 + 托盘）
python scripts/cli.py web              # 或纯 Web 看板（http://127.0.0.1:8765）
```

数据抓取、信号、回测等研究层能力见 `scripts/cli.py` 子命令（`daily` / `signal` 等）。LLM 密钥配置在 `config/settings.local.yaml`（已 gitignore）。回测引擎与聚宽逐笔对标校准（盈亏误差 < 1%），供研究者复现结论。

**技术栈**：Python · Flask · SQLite · Vue 3 · ECharts · pywebview · PyInstaller + Inno Setup · 多免费 LLM 自动故障切换（akshare / TA-Lib 支持数据与指标）
