# 量价关系规则表(阶段3,依《量价关系》陈凯 完善)

> 规则来源:《量价关系——透视股票涨跌脉络》(陈凯),经全文提取整理;全部确定性代码
> (`alphaprism/signals/volprice.py` + `signals.py`),阈值参数化。
> 书中无明确数值处均已标注"书中无明确数值",并给出符合书意的可调建议。

## 书中核心原则(编码前提)

1. **量价只做确认/预警层,不独立开仓**——趋势判断只用 K线高低点(与"分型→笔→结构"契合)。
2. **背离有两层**:第一层次 = **量增价不涨/不跌**(最主要的背离);第二层次 = **缩量上行/下行**(有慢牛反例,不能一刀切)。
3. **缩量不是卖点、缩量突破≠假突破**——必须区分上下文(放量下跌末端后 vs 放量整理后/长期上升后)。
4. **顶背离强于底背离**:底背离需反复多次确认;顶背离(放量不涨)成立即退场。
5. **小周期背离不可靠、收敛图中背离无效**——必须叠加在已判趋势上。

## 修正后的核心规则

### R1 买点确认:放量反包(书修正)
- 结构底 + 近支撑 + **放量反包**(今收>昨高 且 量>1.5×)。
- 书中警示:底部反包"一般不具迅速上攻能力",需反复确认;**底背离不单独作买点**。

### R2' 卖点确认:量增价不涨(主) / 高换手 / MACD顶背离(书修正,替换原"缩量=卖")
- **量增价不涨**(第一层次背离):放量滞涨持续 ≥4 日,价格波动 <3%。
- **高位换手率 >10%** ≈ 临界点。
- **MACD顶背离**:价创新高 + DIF未创新高 + 连续2根DIF向下。
- ~~缩量上攻=卖~~ **删除**:缩量上涨分两种(放量整理后=慢牛持有;放量下跌末端后=无量反弹弹不远),需上下文,不作无条件卖点。

### R3 天量天价 / 地量地价(书修正)
- 天量:>2×,须绑定位置——趋势早期=启动延续,高位+滞涨/大阴线=见顶预警。
- 地量:<0.4×(或20日最低),只作"整理接近尾声"观察,**不单独触发买卖**(书中明确否定"地量后放量=直接买点")。

### R4' 关键位突破(书修正,替换"缩量突破=假突破")
- 突破默认需**放量**(≥1.5~2×)+ 量增价升;缩量突破=**存疑不追**,等补量站上或回踩不破再确认。
- 书中无"缩量突破=假突破"的绝对表述;一字板无量突破(惜售)和慢牛缩量新高都是真突破。

### R5' 顶背离(书修正)
- 主形式 = **量增价不涨**(见 R2')。
- "价新高量萎缩"是第二层次,仅作观察:放量整理后缩量新高=慢牛;加速段后缩量上涨+力度衰减=衰竭;M头第二头缩量=头部辅助。

### R6' 底背离(书修正,仅观察)
- 价新低 + 量不再萎缩/放大 = 底背离,只作观察;**弱于顶背离,需反复/日线至少两次**,不作为独立买点。

## 编码时务必遵守的警示(书中明确)

1. 地量后放量 ≠ 直接买点(需推演次日回调/切入价/止损)。
2. 缩量上涨 ≠ 卖点;缩量突破 ≠ 假突破(有真突破反例)。
3. 背离须过滤:小周期不可靠、收敛图中无效、底背离弱于顶背离。
4. 量价是共振层,不是独立信号源。
