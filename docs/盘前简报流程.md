# 盘前简报流程(阶段4:消息面 LLM 模块)

> 用途:每日盘前/下单前,确认技术信号是否有**未兑现**的政策 / 事件驱动配合。
> 催化剂状态四档:**增强 / 减弱 / 新增 / 未变**。
> 依据:确定性数据(异动/热榜/拥挤度/估值)+ 财经新闻(Wind MCP)→ LLM 只做解读。

## 一、数据准备(确定性,先跑)

| 步骤 | 命令 | 拿到什么 |
|---|---|---|
| 1 | `alphaprism daily`(或 `signal`) | 结构状态、关键价位(支撑/压力)、当前信号 |
| 2 | `alphaprism catalyst [代码...]` | 当日板块成分股异动(涨停/大涨 + 原因)、热榜归属 |
| 3 | `alphaprism sector` | 板块成交占比(拥挤度,≥15% 警戒 / ≥20% 强警示) |
| 4 | `alphaprism valuation` | 板块中位 PE/PB vs 沪深300(月度用,盘前可不跑) |
| 5 | `alphaprism wind financial_docs get_financial_news query=<主题> top_k=5` | 财经新闻深挖(板块 / 龙头 / 政策) |

> 步骤 2 的结果已写入日报「六、消息面」;步骤 5 是 LLM 解读时按需调用的深挖通道
> (Wind MCP,agent 通道,计入每日 1000 积分)。

## 二、LLM 解读规则(催化剂状态判定)

对每只 ETF 的板块,回答:今天发生了什么(异动/新闻/政策)、相对昨天是变强还是变弱。

| 状态 | 判定标准(示例) |
|---|---|
| **增强** | 新增重大催化(政策落地/龙头事件/涨价),或板块当日涨停潮+资金流入 |
| **新增** | 首次出现明确事件驱动(如新政策、龙头新品、业绩预增超预期) |
| **减弱** | 事件兑现(利好出尽)、龙头走弱、成交占比从高位回落、禁令/监管风险 |
| **未变** | 无明显新事件,走势与催化剂现状一致 |

**护栏**:
- 催化剂只做**验证层**,不独立开仓 —— 技术结构没到买点,催化剂再强也不进(§2.2)
- 催化剂状态要与**上一日**比较,给出"较昨日"的变化,避免只看今天
- 个股异动≠板块催化:单只涨停可能是个股事件(中标/并购),要在解读中区分
- 消息面数据(异动解读、新闻)是**快照**,下单前复核最新(尤其周末后)

## 三、盘前简报输出格式(§6.2)

```markdown
# AlphaPrism 盘前简报 YYYY-MM-DD

## 一、催化剂状态(较昨日)

| 代码 | 名称 | 结构 | 催化剂状态 | 依据(当日异动/新闻/政策) |
|---|---|---|---|---|

## 二、今日关键价位与信号

(每只 ETF:支撑 / 压力 / 当前信号 / 结构)

## 三、风险清单(出现什么情况该离场)

(结构性止损位 / 催化剂反转信号 / 拥挤度强警示)

## 四、大概率情景(带条件表述)

"若站上 X 且放量,则偏强;若跌破 Y 则离场。"
```

## 四、产出与存档

- 保存到 `reports/盘前-YYYY-MM-DD.md`
- 催化剂状态进入信号日志(§6.4),供长期评估
