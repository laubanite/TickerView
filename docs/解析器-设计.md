# 解析器设计(里程碑1,产品方案 §4.1)

> 状态:已落地 | 日期:2026-08-20 | 模块:`alphaprism/planner/`

## 目标

把"自然语言 + 表格"的作战地图 `.md` 解析成机器可核对的结构化 **RuleModel**。
这是核对引擎(里程碑3)的输入契约,也是用户自定义作战地图(§5.7)的写入目标——
**解析器读、生成器写,共用同一个 RuleModel schema**。

## RuleModel 结构

见 `alphaprism/planner/rulemodel.py`(dataclass 定义,可直接 `to_dict()/to_json()`)。
顶层:

```
RuleModel
├─ meta        : 文档日期 / 版本 / 数据来源 / 适用原则 / 源文件
├─ global_     : 组合层
│  ├─ market_gate : 大盘门控(收盘/均线/MACD/KDJ/压力/支撑/结论/门控规则)
│  ├─ budget_total / budget_items : 弹药预算
│  ├─ discipline / risks : 通用纪律 / 风险提示
├─ instruments : 标的层(每只)
│  ├─ code/name/type(波段仓|解套仓)
│  ├─ position : 持仓(只展示,不做决策)
│  ├─ levels   : 关键价位(买区/突破点/减仓红线/生命线/压力/支撑,带溯源)
│  ├─ rules    : 触发规则(动作×条件×操作,仅可计算条件)
│  └─ alerts   : 非数值预警/催化(不可计算项)
├─ daily       : 日级层
│  ├─ playbook : 剧本修正表
│  └─ journal  : 每日盯盘记录(按日期追加)
├─ unresolved  : 待人工确认队列(解析器不猜测)
└─ warnings    : 解析告警(勘误等)
```

## 章节 → 字段映射

| 作战地图章节 | RuleModel 字段 | 解析方式 |
|---|---|---|
| 文档头 | meta | 键值对抽取(文档日期/数据来源/版本/适用原则) |
| §一 大盘环境 | global_.market_gate | 表格(收盘/均线/MACD/KDJ/压力/支撑)+ 环境结论 → 门控规则 |
| §二 持仓一览表 | instruments[].position | 表格解析(列名固定) |
| §三 逐只分析 | instruments[] | 按 `### N. 名称 代码` 切块;关键位地图 → levels;操作建议表 → rules;基本面预警 → alerts |
| §四 预警速查表 | instruments[].alerts | 表格解析(品种→标的) |
| §五 资金分配 | global_.budget | 可用子弹 + 预算占比表 |
| §六 通用纪律 | global_.discipline | 编号列表 |
| §七 风险提示 | global_.risks | 编号列表 |
| §八 触发信号速查 | instruments[].levels + type | 买点/突破/减仓红线/生命线并入 levels;红线溯源原则注 → 波段仓/解套仓分类 |
| 每日盯盘记录 | daily.journal + playbook | 按 `### 📅 日期` 切段;剧本修正表 → playbook |

## 三条硬约束(与产品方案一致)

1. **数字必溯源** — levels 每个价位的 `source` 标注锚定(MA20/8/14低/生命线等)。
   无法溯源的保留空 source,不编造。
2. **不可计算进 alerts 不进 rules** — 触发条件含"情绪面/消息面/预期/政策"等主观词
   → 转 `unresolved` 待确认 + 该标的 alerts,绝不放进 rules(核对引擎无法算)。
3. **解析失败/有歧义 → unresolved,绝不猜测** — 任何无法确定的内容进待确认队列,
   由人工处理。这条约束同时保护解析器和 §5.7 生成器。

## 使用

```bash
alphaprism battlemap                 # 默认摘要(自动找 AITrader 最新一份)
alphaprism battlemap <path>          # 指定地图
alphaprism battlemap <path> --json   # 完整 RuleModel JSON
```

Python:

```python
from alphaprism.planner.parser import parse_file
model = parse_file(r"E:\AITrader\七只ETF作战地图_2026-08-17.md")
model.summary()          # 摘要 dict
model.to_json()          # 完整 JSON
model.instrument_by_code("516020")
```

作战地图路径可在 `config/settings.yaml` `battlemap.path` 配置,留空自动探测。
