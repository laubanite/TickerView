### C5' 市场状态机:五级场景 + 布尔状态词(废止计分制)

判定顺序与场景定义 = 交易系统设计 §8.1(先中者先算):

| 优先级 | 场景                 | 布尔条件(全部可复核)                                                  | 状态词(白名单)                                    |
| ------ | -------------------- | --------------------------------------------------------------------- | ------------------------------------------------- |
| 1      | 破位                 | 放量(成交额≥1.5×20日均)跌破关键位**且性质=趋势破坏**          | 破位退出                                          |
| 2      | 突破异动日           | 均线粘合(极差<阈值)+ 单日收盘放量站上区间上沿/关键位                  | 右侧初现(①A≤满配10%)                            |
| 3      | 变盘前兆             | 均线粘合 + 放量持续≥2 日,未站上上沿                                  | 变盘前兆                                          |
| 4      | 区间震荡(家族全覆盖) | 均线粘合且当日无放量有效动作;子态:中部/上沿收敛/下沿测试/量能异动观察 | 区间震荡(禁用左右侧)                              |
| 5      | 趋势                 | 均线发散,非以上四者 → 右侧/左侧体系                                  | 左侧观望/超跌试多/蓄势/右侧初现/右侧确认/破位退出 |

要点:

- **无计分**:状态词 = 布尔条件组合,不存在"40 分=蓄势、70 分=右侧"的连续档;
- **单日诚实**:单日截面只有 左侧/蓄势/右侧初现;**右侧确认由盘后增量1 跨日推进**(架构 §五·增量1),盘中组件不输出"右侧确认";
- **收盘确认(v2.1)**:盘中"放量站上"只产生**右侧初现(待收盘确认)**,身份升级(反弹压力位→突破加仓位/回踩带候选)以**日线收盘站上**(右侧)或**30分K 收盘确认**(转换有效性)为准——盘中瞬时穿越不驱动身份(交易系统设计 §6.1.1);
- **②-A/②-B 拆分**:条件=交易系统设计 §3.5——时间确认(次日收盘不破突破位)→②-B 先头仓(≤满配22%,止损=突破位下一档);结构确认(缩量回踩+企稳三选一)→②-A 主力仓(≤满配45%,止损=回踩低点下);合计 ≤45%。

### C4' 操作参数档位 v3:身份 × 价位 × 位源(取代"校验五条")

**档位 = `身份词 + 价位 + 位源 + 动词白名单` 四元组**,由规则表生成,LLM 只许照抄。规则 = 交易系统设计 §6.1(本表只列实现要点):

输出结构:

```
{
  身份: 突破加仓位|反弹压力位|回踩加仓位(区间)|无回踩结构|减仓档|清仓止损档|保本线(动态),
  价位: 标量或 (上沿, 下沿) 二元组,仅取 C1' 白名单位源,
  位源: 支撑类|压力类|止损类(§6.1.2 排序:价格距离优先,同位次 前高>均线>整数关口),
  动词白名单: 按 §6.1.1 身份表,
  校验: 七条(见下), 完整性按场景(有结构四档/无结构三档)
}
```

- **位源扩展(v3)**:支撑类 = 日线 M5/M10/M20/M60、30分 M5/M10/M20、30分近60根区间下沿、日内低点、共振带下沿、转换位(上快照突破位未被 30分K 收盘跌破,读 `advice_archive`,断档/>20 交易日兜底不启用);**结构压力类(突破档候选,§3.1)= 近20日区间上沿、前高平台、共振带上沿、阶段高点——日线均线上方不作突破档,只作「均线压力带」参考(空头里 M5 日日下移会退化)**;上方无结构位时 fallback 最近均线并标记 `breakout_is_ma=True` → 身份=反弹压力位;止损类 = 250日阶段低点、前低平台、近20日区间下沿;
- **回踩带三阈值**:上沿距现价 > 3×ATR20 → 无有效回踩结构(§6.1.1 空头排列分支,只出三档,盘面状态标"回踩 无结构");下沿 = 上沿下方 ≤1.5×ATR20 的最近支撑源(超距 → 单点带);上沿距现价 ≤ max(0.5%, 0.5×ATR20) → 已到位/带内企稳观察;回踩失败 = 先入带再破下沿,直接破上沿 = 直接破位;
- **减仓档** = 回踩带下沿(跌破 30分K 收盘确认)或近20日区间下沿/前低平台(无结构分支);**清仓止损档 = 最下档**(止损类位源最低者),仅当白名单无任何低位源(数据残缺)才显式"缺档",LLM 禁止写"止损暂未设定"。

校验清单(交易系统设计 §6.1.4,任一违反=参数无效):

```
① 突破档(仅当存在"突破加仓位/反弹压力位"身份时)> 锚定价
② 回踩带上沿 ≤ 锚定价(触发≠校验,§2.4)
③ 回踩带下沿 ≥ 减仓档(允许相等——下沿双身份:企稳观察/跌破减仓)
④ 清仓止损档 < 减仓档
⑤ 清仓止损档 − 减仓档 ≥ max(0.5%, 1×ATR20)
⑥ 位源类别:回踩带 ∈ 支撑类 / 压力档 ∈ 压力类 / 减仓·止损 ∈ 区间下沿·阶段低·前低平台
⑦ 完整性按场景:有回踩结构 → 四档齐备;无回踩结构 → 三档齐备(允许缺回踩带)
```

- 保本线 = 动态档(浮盈保护激活后存在,≥综合成本线),**不参与静态校验**;跌破 → 右侧全部仓位(含①A)全清,锚点按三态(交易系统设计 §6.1);
- 触发 ≠ 校验:回踩触发瞬间实时价≈回踩价,不做"回踩<实时价"运行时校验(交易系统设计 §2.4);
- **支撑/压力动态转换**(§6.1.5):读最近归档 → 上快照突破位(现价已站上且未被有效跌破)→ 本次进支撑类候选(只取最近一个);上快照支撑位被放量跌破(性质趋势破坏)→ 排除出承接候选。无数值权重(×0.7 等一律不采纳)。
